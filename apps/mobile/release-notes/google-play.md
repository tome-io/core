# Google Play release notes

## Writing rules

- Write for readers, not developers.
- Use three to five short bullets and stay below Google Play's 500-character limit.
- Describe visible improvements and benefits in plain language.
- Do not mention internal implementation, issue numbers, or routine maintenance.
- Include only changes available in the uploaded build.

## Current release
