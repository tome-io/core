# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

# Platform UI

- Keep screen composition and information architecture consistent across iOS and Android.
- On iOS, prefer native Expo Router navigation, SwiftUI controls, SF Symbols, and system Liquid Glass styling.
- On Android, use Tomeio's existing custom React Native controls and visual styling for the same actions.
- Do not imitate iOS controls with custom React Native components when an appropriate native iOS API is available.
